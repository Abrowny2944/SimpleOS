<b>SimpleOS</b>

A custom WebOS

Apps:
* Info app
* Document editor app
* Weather app
* Settings app
* Calculator app
* Turbowarp packager app

Features:
* Wallpaper changing feature in settings
* Draggable windows
* Ability to open and close apps
